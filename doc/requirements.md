# Requirements

- As a user, I should be able to be able to make an encrypted file, password.enc.txt, from passwords.txt.
- As a user, I should be able to upload the encrypted data into MongoDB.
- As a user, I should be able to be given true or false from the software when I give email addresses and passwords.
- As a user, I should be given true from the software if I input a correct email and password pair.
- As a user, I should be given false from the software if I input a correct email and incorrect password.
- As a user, I should be given false from the software if I input a incorrect email and correct password.
- As a user, I should be given false by the software if I input an email not in the password file.
- As a user, I should be given false by the software if I do not input a email.
- As a user, I should be given false by the software if I do not input a password.
